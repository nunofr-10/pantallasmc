Configuración de señal

Cambia lo que quieras y pulsa guardar: todas las pantallas abiertas en index.html se actualizan solas en cuestión de segundo y medio, sin que nadie recargue nada.

Falta un paso previo: esta página necesita la Database URL de un proyecto Firebase gratuito (es el "buzón" compartido entre config.html e index.html; GitHub Pages no puede guardar estado por sí solo).

  1. Entra en console.firebase.google.com y crea un proyecto (gratis, sin tarjeta).
  2. En el menú, ve a Realtime Database → Crear base de datos (modo prueba).
  3. Copia la URL que aparece arriba, tipo https://tu-proyecto-default-rtdb.europe-west1.firebasedatabase.app.
  4. Pégala en la constante DB_URL, al principio de este archivo y de index.html, y sube el cambio a GitHub.
  5. En la pestaña Reglas de Realtime Database, pon {"rules":{".read":true,".write":true}} y publica (así ambas páginas pueden leer/escribir sin login; solo quien tenga la URL puede tocarlo).

Es un paso único. Después de esto, todo funciona solo.
